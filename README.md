# Statements — on-device statement analyzer

A tiny installable web app that parses DBS credit-card / bank / PayLah!
statement PDFs **entirely in your browser** and shows true spending, monthly
cash flow, categories, and things to check.

- **No server, no upload**: PDFs are parsed on-device (bundled pdf.js);
  data lives in your browser's local storage only.
- Personal rules & history are imported privately by each user — this repo
  contains no personal data.
- Works offline after first load; add to home screen for the app experience.
